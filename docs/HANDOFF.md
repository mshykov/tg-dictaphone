## Відкриті питання / ризики

- **Парсер екрана — найкрихкіше місце.** Він евристичний поверх TUI
  Claude Code. Фікстур поки 1 реальна + 15 синтетичних. Кожен глюк
  розпізнавання → `/dump <очікуваний_стан>` → зачистити знімок →
  полагодити `screen.py`.
- **`claude.exe` як ім'я процесу** — саме так виглядає
  `pane_current_command` на цій машині. Якщо агент запускається інакше
  (через wrapper, `zsh -c`, tmux `respawn`), fail-closed заблокує
  надсилання — тоді або `/bind` на правильну панель, або розширити
  `AGENT_HINTS`.
- **Питання без «?»** дають стан `idle` (реальна фікстура це показує:
  агент закінчив «Скажи, коли продовжити…» — це не `waiting`). Свідомий
  компроміс проти хвилі фальшивих `waiting`; хвіст екрана в панелі все
  одно видно.
- **launchd не бачить brew PATH** — plist у README вже задає PATH; при
  автозапуску перевір, що бот бачить той самий tmux-сокет.
- Telegram bot-чати **не e2e-шифровані**: `/screen` показує вміст
  термінала через сервери Telegram.
