перед комітом прогони tests/test_screen.py; репозиторій публічний —
жодних реальних логів/токенів/внутрішніх назв у комітах.

## Чек-лист приймання (перший E2E-прогін)

Позначай тут, що працює. Це і є критерій «v2 готовий».

### Базове

- [ ] бот стартує без PREFLIGHT-попереджень
- [ ] на старті приходить привітання з прив'язкою панелі `%0 (claude.exe)`
- [ ] `/status` — сесія ✅, панель `%0`, `claude.exe`, «агент», стан
- [ ] `/peek` — панель зі станом, стан збігається з тим, що на екрані Mac
- [ ] `/screen` — останні 60 рядків, згортання/розгортання працює
      і **не скидається** при 🔄 (це був баг v1)

### Надсилання

- [ ] текст → підтвердження → надсилається, промт з'являється в tmux
- [ ] голосове → транскрипція → підтвердження → надсилається
- [ ] «Друкує…» не гасне під час довгої транскрипції
- [ ] багаторядковий текст доходить одним промтом (bracketed paste),
      а не кількома
- [ ] текст, що починається з `-` (напр. `-- test`), не ламає надсилання

### Fail-closed (головна безпекова гарантія)

- [ ] у tmux вийти з Claude (щоб у панелі був `zsh`) → надіслати текст →
      бот **блокує** з ⛔️ і кнопкою «Все одно надіслати»
- [ ] override працює, і в підтвердженні видно, що надіслано примусово
- [ ] `/bind` після повернення Claude знову прив'язує панель

### Кнопки й покоління

- [ ] у діалозі Claude (напр. запит дозволу) з'являються кнопки
      варіантів із текстом
- [ ] натискання цифри вибирає варіант
- [ ] чекбокс-діалог: ↑ ↓ ␣ ⏎ працюють, панель оновлюється
- [ ] **стара панель**: зробити /peek двічі, натиснути кнопку на
      ПЕРШІЙ → «Панель застаріла — ось свіжа», у термінал нічого не йде
- [ ] ⛔️ Перервати (Escape) працює **під час** роботи агента —
      це перевірка, що бот не заблокований (був баг v1)

### Фоновий нагляд

- [ ] після надсилання приходить «⏳ Стежу за реакцією…»
- [ ] коли агент відповів — приходить нова панель автоматично
- [ ] довга задача (>3 хв): приходить heartbeat «ще працює · N хв»
- [ ] дуже довга задача не «зникає» без сповіщення (стеля
      `WATCH_MAX_SECONDS`, за замовчуванням 30 хв, потім чесне
      «перестаю стежити»)

### Стійкість

- [ ] `/dump idle` зберігає фікстуру і попереджає про зачистку
- [ ] вбити tmux-сесію → `/peek` каже «сесії не існує» (не «вільна»)
- [ ] рестарт бота: кнопки з попереднього запуску нічого не надсилають
- [ ] у груповому чаті бот мовчить (якщо є де перевірити)

### Після приймання

- [ ] launchd plist встановлено, бот піднімається після ребуту
- [ ] `~/bin/tg_dictaphone.py` архівовано/видалено, щоб не запуститись
      випадково
