# tg-dictaphone — правила проєкту для Claude

Telegram-бот, що працює голосовим/текстовим пультом до tmux-сесії з агентом
(Claude Code) на Mac власника. Python 3.13, `python-telegram-bot` 22, локальний
Whisper (`mlx-whisper`). Репозиторій **публічний**.

> Цей файл — хаб: тут лише правила, які не можна порушувати, і посилання на
> документи. Деталі — в `docs/`.

## Інваріанти — не ламати

Бот вставляє текст у живий термінал, тож помилка тут = виконана не та команда.
Повне пояснення в `docs/ARCHITECTURE.md`; коротко:

1. **Тільки прив'язана панель.** Жодних tmux-викликів з `-t SESSION` — лише
   через `tmuxio`, лише в `PANE["id"]`.
2. **Fail-closed.** Кожен новий шлях, що вставляє текст, спершу перевіряє, що в
   панелі агент (`AGENT_HINTS`).
3. **Покоління кнопок.** Кнопка діє тільки для панелі, для якої її намалювали
   (`gen` у `callback_data`); невідома дія ніколи не трактується як
   підтвердження; клавіші — лише з `KEY_ALLOW`.
4. **Текст як текст.** Вставка через `load-buffer` + `paste-buffer -p` під
   `SEND_LOCK`, потім окремий `Enter`. Ніколи `send-keys` для тексту промту.
5. **Тільки власник, тільки приватний чат.**

## Перевірки

```sh
~/.venvs/tgbot/bin/python tests/test_screen.py
```

Парсер екрана (`screen.py`) — найкрихкіша частина; кожен баг парсера
закривається фікстурою в `tests/fixtures/` і тестом, що її жене.

## Публічний репозиторій — що сюди не потрапляє

- **Секрети** живуть у `~/.config/tgbot.env` (chmod 600) — ніколи в git.
  Локальні нотатки — у `_do-not-commit/` (gitignored).
- **Фікстури** — це знімки реального термінала. Перед комітом перечитай
  фікстуру і прибери внутрішній/чутливий вміст, зберігши структуру екрана
  (рамки, спінер, промт, статус-бар) — саме її перевіряє тест.

## Статус

компіляція й парсер. Перед перемиканням з v1 дивись `docs/HANDOFF.md`.
